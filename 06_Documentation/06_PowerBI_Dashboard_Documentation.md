**Power BI Dashboard Documentation**



**1. Introduction**



The Power BI Dashboard was developed as part of the SWYNEX Technologies Final Data Analytics Project to present student performance information through interactive and visually understandable reports.



The dashboard transforms the cleaned student dataset into meaningful visual insights, allowing users to explore student academic performance and examine patterns across different student-related factors.



Power BI was used to create an interactive dashboard that supports data exploration and analytical decision-making.



**2. Objectives of the Dashboard**



The main objectives were:



\- Present student performance information in a visual format.

\- Monitor important academic performance indicators.

\- Understand patterns across student-related categories.

\- Compare examination performance across different groups.

\- Provide interactive filtering capabilities.

\- Make complex data easier for stakeholders to understand.

\- Support data-driven educational decision-making.

**5. Dashboard Design and Layout**



The dashboard was designed to organize important student performance information into a structured visual layout.



The design focuses on:



\- Clear presentation of important metrics.

\- Appropriate use of charts.

\- Organized placement of visual elements.

\- Easy navigation and filtering.

\- Consistent formatting.

\- Improved readability.



The objective was to create a dashboard that allows users to understand important information without manually examining thousands of individual records.



**6. Key Performance Indicators (KPIs)**



KPI cards provide a quick overview of important metrics.



Depending on the measures implemented in the dashboard, these indicators can include:



\- Total Students – Number of student records.

\- Average Exam Score – Average examination performance.

\- Average Attendance – Average student attendance.

\- Average Study Hours – Average number of hours studied.



These indicators help users understand the overall dataset at a glance.

**8. Interactive Filters and Slicers**



Slicers allow users to filter dashboard information dynamically.



Depending on the slicers implemented, users can explore student records based on:



\- Gender.

\- School Type.

\- Motivation Level.

\- Parental Involvement.

\- Other available student categories.



These filters make it easier to compare different groups without creating separate reports.



**9. Dashboard Interactivity**



Interactive features improve the usability of the dashboard.



The dashboard can support:



\- Dynamic filtering through slicers.

\- Cross-filtering between compatible visuals.

\- Interactive chart selections.

\- Comparison of student categories.

\- Exploration of filtered performance metrics.



Only the interactive features actually configured in the final Power BI report should be considered completed features.



**10. Reset Filters Functionality**



A reset filters feature can improve dashboard usability by allowing users to return to the default dashboard view after applying multiple filters.



When configured correctly, the reset functionality restores the intended default slicer selections and report state.



This makes it easier to restart analysis without manually clearing every filter.

**15. Limitations**



\- The dashboard is based on the available dataset.

\- The dashboard does not independently establish causal relationships.

\- Insights depend on the accuracy and completeness of the source data.

\- Additional educational indicators may provide deeper analytical context.

\- The dashboard is intended for analysis and reporting rather than automated student performance prediction.
