**8.1 Project Overview**



The Student Performance Analytics project was completed as part of the SWYNEX Technologies Internship – Task 4: Final Data Analytics Project.



The project focuses on analyzing student academic performance using data analytics tools and techniques.



The dataset contains 6,607 student records and 20 columns, providing information about students' academic, behavioural, and educational factors.



The primary objective was to transform raw student data into meaningful insights that can support educational analysis and data-driven decision-making.



**8.2 Project Objectives Achieved**



The project addressed the following objectives:



\- Prepared and cleaned the student performance dataset.

\- Identified and handled data quality issues.

\- Performed structured data analysis using SQL.

\- Conducted Exploratory Data Analysis using Python.

\- Analyzed relationships between student-related attributes and examination performance.

\- Developed an interactive Power BI dashboard.

\- Identified important analytical areas and developed business recommendations.

\- Organized the project into a structured and professional documentation format.

**8.6 Project Limitations**



Although the project provides useful insights into student performance, certain limitations should be considered.



\- The analysis is based on the available dataset and its attributes.

\- The findings may not represent every educational institution or student population.

\- Some factors influencing academic performance may not be included in the dataset.

\- Observational relationships do not establish cause-and-effect relationships.

\- The analysis reflects the available data rather than long-term changes in student performance.



These limitations should be considered when interpreting the findings and applying recommendations.
