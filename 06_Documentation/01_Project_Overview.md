**Student Performance Analytics**

**SWYNEX Technologies – Internship Task 4**



**1. Project Overview**



The Student Performance Analytics project is an end-to-end data analytics project developed as part of the SWYNEX Technologies internship – Task 4: Final Data Analytics Project.



The project focuses on analyzing student academic performance and identifying the factors that may influence students' examination outcomes.



The analysis uses a structured student performance dataset containing 6,607 records and 20 columns. The project follows a complete data analytics workflow, starting from data cleaning and preparation to exploratory data analysis, SQL-based analysis, and interactive dashboard development.

**3. Business Problem Statement**



Educational institutions collect student-related information to evaluate academic performance and understand learning outcomes.



However, analyzing large datasets manually can make it difficult to identify performance patterns, understand relationships between different student-related factors, and recognize areas that may require improvement.



This project addresses the need for a structured analytical approach to examine student performance data and generate meaningful insights that can support data-driven educational decisions.



**4. Project Objectives**



The primary objectives are:



1\. Clean and prepare the raw student performance dataset.

2\. Identify and handle missing values, duplicate records, and data inconsistencies.

3\. Perform SQL-based analysis to answer relevant business questions.

4\. Conduct Exploratory Data Analysis using Python.

5\. Identify patterns and relationships within the dataset.

6\. Develop an interactive Power BI dashboard.

7\. Present analytical findings through meaningful visualizations.

8\. Provide data-driven recommendations based on verified findings.



**5. Project Scope**



The project covers the following analytical activities:



\- Dataset inspection and understanding.

\- Data cleaning and preparation using MySQL.

\- Exploratory Data Analysis using Python.

\- Statistical summaries and graphical visualizations.

\- SQL-based business analysis.

\- Interactive dashboard development using Power BI.

\- Documentation of methodology and analytical findings.

\- Presentation of business insights and recommendations.



**6. Project Methodology**



The project follows an end-to-end data analytics workflow.



**Phase 1 – Data Cleaning and Preparation**



The student performance dataset is inspected, cleaned, and prepared using MySQL to improve data quality and consistency.



**Phase 2 – Exploratory Data Analysis**



Python, Pandas, and Matplotlib are used to explore the dataset, understand distributions, identify patterns, and visualize relationships.



**Phase 3 – SQL Analysis**



SQL queries are used to perform structured analysis and answer relevant questions about student performance.



**Phase 4 – Power BI Dashboard**



An interactive dashboard is developed using Power BI to present key performance indicators, comparisons, and analytical findings.



**Phase 5 – Documentation and Reporting**



The complete workflow, analytical methods, findings, and recommendations are documented for professional project presentation.

**9. Project Limitations**



The analysis is based on the available dataset and its recorded attributes.



The findings should be interpreted within the limitations of the available data. Observed relationships do not necessarily establish cause-and-effect relationships.



The project does not claim to predict future academic performance unless a separate predictive model is developed and validated.
